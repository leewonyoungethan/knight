# 삼도류 검사 (Three-Sword Style)

`index.html` 하나로 된 얼굴을 가린 어둠의 기사가 칼 세 자루(오른손·왼손·입)를 쓰며 성장하는 오리지널 2D 도트 액션 플랫포머예요.

- 10개 월드 × 4스테이지 = 40스테이지: 숲, 동굴, 성벽, 사막, 설원, 늪, 용암, 하늘섬, 폐허, 공허
- 월드마다 x-4는 서로 다른 보스: 바위왕, 슬라임 대왕, 흑기사, 모래 지렁이, 서리 마녀, 독두꺼비, 화염 정령, 폭풍 그리폰, 해골 사령술사, 별을 삼킨 자(3페이즈, 가장 어려움)
- 적을 쓰러뜨려 레벨업(체력·공격력 상승), Lv5 회오리베기(땅에서 ↓+공격), Lv8 검기 날리기(3타)
- 3단 콤보(오른손 베기 → 왼손 올려베기 → 삼도 교차베기), 2단 점프, 벽 점프, 대시, 별 던지기(주워 모은 별을 써요), 공중 ↓+공격 내려찍기
- 월드마다 다른 칩튠 배경음악(보스전·최종 보스·상점·타이틀 곡 따로), 콤보 카운터
- 필살기: 삼검 돌파(L, 쿨타임 6초) · 흑풍 회오리(U, 쿨타임 10초) / 궁극기: 흑월참(I, 게이지 1500을 채우면)
- 스테이지 사이 상점에서 검 10종(처음엔 철 일본도 세 자루, 나머지는 해적·바다 모험 테마 칼 · 오른손·왼손·입 칸에 따로), 갑옷 10종을 사고 칼을 +10까지 강화해요. 진행 상황은 이 기기에 저장돼요.
- 키보드: A/D 이동 · W/Space 점프 · J 공격 · K 대시 · L·U 필살기 · I 궁극기 · Esc 일시정지 · M 소리
- 휴대폰에서는 왼쪽 조이스틱과 오른쪽 버튼으로 해요. 게임패드도 돼요.
- 🏆 순위: Claude 링크에서 열면 모두의 기록(도달 스테이지·시간)을 함께 봐요. GitHub Pages에서는 Supabase를 연결하면 모두의 순위가 보여요(설정 전에는 이 기기 기록만).

## 하는 법

`index.html`을 브라우저로 열면 돼요. GitHub Pages를 켜면 인터넷 주소로도 할 수 있어요.

## GitHub Pages에서 모두의 순위 켜기 (Supabase, 무료)

1. https://supabase.com 에 가입하고 새 프로젝트를 만들어요.
2. 왼쪽 **SQL Editor**를 열고 이 저장소의 `supabase.sql` 내용을 통째로 붙여 넣은 뒤 **Run**을 눌러요.
3. **Project Settings → API**(또는 **Connect**)에서 **Project URL**과 **anon / publishable 키**를 복사해요.
4. `index.html`에서 `const SUPA={url:'',key:''};` 줄을 찾아 두 값을 넣고 저장해요.

anon(publishable) 키는 원래 공개되는 키라 저장소에 올려도 돼요. 순위표는 누구나 읽을 수 있고, 기록은 각 기기만 아는 비밀값으로만 고칠 수 있어요.
점수는 브라우저에서 보내기 때문에 마음먹고 조작하는 사람까지 막지는 못해요.
