# 별빛 기사 (Starlight Knight)

`index.html` 하나로 된 오리지널 2D 도트 액션 플랫포머예요.

- 10개 월드 × 4스테이지 = 40스테이지: 숲, 동굴, 성벽, 사막, 설원, 늪, 용암, 하늘섬, 폐허, 공허
- 월드마다 x-4는 서로 다른 보스: 바위왕, 슬라임 대왕, 흑기사, 모래 지렁이, 서리 마녀, 독두꺼비, 화염 정령, 폭풍 그리폰, 해골 사령술사, 별을 삼킨 자(3페이즈, 가장 어려움)
- 3단 검 콤보, 2단 점프, 벽 점프, 대시, 별 던지기(주워 모은 별을 써요), 공중 ↓+공격 내려찍기
- 스테이지 사이 상점에서 검 10종(공격력·사거리), 별 10종(쌍둥이·번개·관통·부메랑·폭발·세 갈래·추적·유성·은하), 갑옷 10종(체력·무적 시간)을 사서 바꿔 껴요. 진행 상황은 이 기기에 저장돼요.
- 키보드: A/D 이동 · W/Space 점프 · J 공격 · K 대시 · L 투척 · Esc 일시정지 · M 소리
- 휴대폰에서는 왼쪽 조이스틱과 오른쪽 버튼으로 해요. 게임패드도 돼요.
- 🏆 순위: Claude 링크에서 열면 모두의 기록(도달 스테이지·시간)을 함께 봐요. GitHub Pages에서는 이 기기 기록만 보여요.

## 하는 법

`index.html`을 브라우저로 열면 돼요. GitHub Pages를 켜면 인터넷 주소로도 할 수 있어요.
